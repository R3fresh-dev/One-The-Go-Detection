# Independently authorized participant raw exports

## Why

AND-EXP-004 requires an approved raw scope, while the current structured export
cannot implement its positive path. Recording, uploading and retaining data do
not grant permission to copy it into a participant download. User authorization
to implement software does not supply a real study or raw-export approval.

## What changes

Add an immutable, independently submitted/reviewed/released `raw_export`
authority for one account generation, study, export purpose and exact retention
policy. Present bounded current choices and a separate unchecked export notice.
Freeze only explicitly selected, currently retained, verified object versions;
assemble them in the existing leased asynchronous ZIP and re-admit at reading,
publication, replay, status and delivery boundaries. Retain metadata-only export
as the default and the existing 50 MiB uncompressed/64 MiB ZIP runtime caps.

## Impact

Canonical operator contract, API export DTO/routes, worker assembly/cleanup,
mobile export selection, archive verification and privacy-job presentation. No
deployment seeds a real authority. Existing privileged laboratory-report access
is not extended by participant eye-video/ECG-waveform export.
