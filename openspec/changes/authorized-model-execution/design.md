# Execution, evidence and release boundaries

Inference uses an RFC 8785 canonical JSON artifact, at most 65,536 bytes, with
explicit ordered feature names, train-only means/scales, finite linear weights,
finite positive probability calibration and approved per-feature limits. Python
pickle, executable loaders, arbitrary feature expressions and unknown algorithms
are refused. Every reference names the actual artifact bucket, model namespace,
non-null version ID, exact byte length and SHA-256.

An operator submits the complete immutable model, frozen evaluation and policies;
different authenticated principals review and release the exact digest. Runtime
database roles cannot write these approvals. Inference resolves current study
membership, notice, consent document, active model and calibration, complete
registry decisions, independent recovery admission, selected attempt evidence,
configuration, method and device binding. This occurs before computation and again
before transactional result commit. Revocation, retirement, deletion, changed
consent or changed calibration interrupts the operation.

The feature contract is otgd.features.v1. Profile values precede the target time;
chemical values require quantified compatible methods, with censored or missing
values retained as missing. Task reaction features use the externally approved
phone/OS/build/clock/presentation/input implementation tuple and timing bias.
Native output itself continues to declare its physical onset unmeasured; software
timestamps alone never create qualification. A personal baseline is owned in the
same data generation, completed before the target, within the explicit approved
age bound of at most 30 days, and independently passes current scope and
acquisition evidence. Its historical delivery time does not replace the current
capture delivery limit.

The scientific threshold and uncertainty policy are prespecified. The engine
applies abstention first. Abstention returns null probability, classification and
threshold; admitted estimates state their research endpoint, population, model
version, threshold and acquisition limits. Result 1.1 binds the frozen snapshot,
context, selected evidence, baseline, features, model artifact, evaluation,
policies, calibration and complete approval history through canonical digests.
These digests protect consistency within authenticated server evidence; they are
not an independent certificate that a scientist approved a human study.

Offline evaluation accepts an explicit bounded dataset and frozen analysis/split
plans. Participant-held-out and later-session rows stay separate from fitting;
all preprocessing is fitted only on the training partition. Chemical-only,
app-only, combined and ECG-removed analyses use identical frozen confirmatory
rows. Invalid and abstaining rows remain visible in all denominators. The report
contains sensitivity, specificity, confidence intervals, Brier score and
calibration error, with exact dataset, plans and artifact hashes. Store, domain,
AWS and physical-device qualification are separately demonstrated release inputs.

The six MODIFIED mobile requirements explicitly supersede the historical
measurement-only inference clauses while preserving their unrelated constraints.
The baseline change is still unarchived: archive production-mobile-platform
before authorized-model-execution so its target capabilities exist. OpenSpec's
archive-order information is not evidence of source completion or release
approval. The shared contract records the versioned exception during review;
legacy-shaped research outputs remain rejected in both old and new binaries.
