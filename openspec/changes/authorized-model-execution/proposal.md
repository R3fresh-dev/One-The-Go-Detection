# Governed research model execution and reproducible evaluation

## Why

The requested authorized research release extends the initial measurement-only
implementation. FULL_SPEC MOD-010 and ADR-013 already describe a conditional P2
research model; generic active flags and constant unavailable capabilities cannot
implement its positive path. Scientific validity still requires independently
supplied study, endpoint, cohort, method, timing and calibration evidence.

## What changes

Implement bounded data-only logistic execution behind the typed independent
registry lifecycle, current owned consent and frozen acquisition evidence. Add a
version 1.1 result carrying its exact scientific scope and authority digest; keep
legacy 0.1 measurement behavior. Provide reproducible offline split, training,
matched ablation and evaluation software. No supplied weights, engineering test
cohort or fixture constitutes a clinically validated model or human study approval.

## Impact

Canonical API worker, operator model/calibration contracts, native timing
qualification, mobile result validation and presentation, and offline research
tooling. This explicitly amends the first measurement-only implementation scope
to the user-authorized conditional P2 research release. Consumer clinical claims,
fitness to drive decisions and personal risk certification remain unavailable.
