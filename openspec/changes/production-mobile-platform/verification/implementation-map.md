## How to read the statuses

| Source status | Meaning |
|---|---|
| Source present | Inspected code implements the responsibility stated in that row. This is not a claim that the complete requirement or every scenario is verified. |
| Partial | A concrete current software gap remains, or a reported fix still needs source re-read. |
| Gate + conditional gap | Safe refusal/foundation exists, but the positive approved-configuration branch has missing software as well as external qualification dependencies. |
| Operations source | Executable infrastructure/deployment/recovery source exists; actual external execution is separate. |
