# Project document index

The repository is the source of record for One-The-Go Detection documents. The selected first milestone includes the physical device, app, and model as one integrated research MVP. Engineering and scientific evidence develop alongside consumer discovery. Historical reports and alternative launch proposals retain their dates and status.
